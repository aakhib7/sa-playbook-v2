# Cross-Border Solution Architecture Playbook (v2)

A single-page work sample showing how I take enterprise and BFSI clients from first call to scale, across languages, cultures and time zones.

**Live page:** https://aakhib7.github.io/sa-playbook-v2/

## What's inside

- **Delivery flow:** seven steps from discovery to post-go-live, each with the common problem and the fix.
- **Live demo:** a KYC message-flow diagram in seven languages (English, Vietnamese, Bahasa Indonesia, Japanese, Arabic with right-to-left layout, Portuguese and French).
- **API kit:** a downloadable Postman collection using HyperKYC SDK terms.
- **Key best practices:** for integration and for communication.
- **Regions:** language and time difference from Bangalore for each market.

## Notes

- Sen Bank is a fictional client.
- SDK terms and status values follow HyperVerge's public Flutter SDK (`hyperkyc_flutter` on pub.dev). Endpoint URLs and the webhook payload are placeholders.
- Translations are AI-drafted and not yet reviewed by a native speaker.
- This is an independent work sample, not an official HyperVerge page.

Built as one self-contained `index.html` with no build step. Open it in any browser.
